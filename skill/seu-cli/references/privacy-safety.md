# 隐私与安全边界

## Cookie

- Cookie 等同于登录凭证，只保存在本机 `~/.seu-cli/session.json`，权限 `0600`。
- 不要索取、回显、记录或转发 Cookie。
- 不要让用户把 Cookie 粘贴到对话里；只让其在本地保存成文件后执行 `auth import --cookie-file`。
- 不要把 `session.json`、浏览器 profile、HAR、截图提交到 Git。

## 不碰的东西

- 不索取账号密码、验证码、滑块验证。
- 不绕过统一身份认证、访问控制、限流或校园网限制。
- 不实现抢课、代签到、自动评教、批量下载等写操作。
- 电子成绩单使用独立账号密码系统，CLI 不接入，也不要代填密码。

## 只读边界

当前所有命令只读。不要尝试通过 CLI 选课、预约、缴费、评教或提交表单；CLI 也不提供这些能力。

## 数据展示

- 成绩、学号、学院、班级、考试座位属于隐私数据。
- 只回显用户明确需要的内容，不要主动展开全部成绩或个人信息。
- 分享截图或日志前先脱敏。

## 失败时

- 报错信息里如果包含 Cookie、token、ticket，展示前要脱敏。
- `PAGE_CHANGED` 不重试；告知用户需要更新 CLI。
- `RATE_LIMITED` 立即停止，不要循环请求。
